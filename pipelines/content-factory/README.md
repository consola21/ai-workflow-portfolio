# content-factory

카드뉴스 원고를 만들고, 게시 시간에 알리고, 매주 제작이 제대로 됐는지 점검해 빠진 회차를 스스로 다시 만드는 3개 작업 묶음.

```
월·목 08:54  produce.md   다음 회차 = 드라이브 폴더 최대 번호 + 1 → 원고·캡션 → 문장 다듬기 → 독립 검증 → 저장
월·목 09:50  notify.md    오늘 회차 폴더가 있으면 "10시 게시" 알림, 없으면 경고
화   08:46  audit.md     produce의 실행 기록 + 결과 파일 확인 → 실패 시 1회 재실행 → 게시물 성과 보고
```

## 핵심 설계

- **상태 저장소 없음.** 회차 번호와 성공 여부를 드라이브 폴더 이름(`게시일_NN_주제`)과 파일(`슬라이드원고.txt`, `캡션.txt`) 존재로 판단한다. 세 작업이 같은 기준을 본다.
- **자동 복구.** audit이 produce의 `last_run` 상태와 결과 파일을 함께 확인한다. 이번 주 회차가 없으면 produce를 1회 재실행(`fire_trigger`)하고, 이미 지난 게시일은 재실행하지 않고 보고만 한다. 작업이 꺼져 있거나 실행 중이면 재실행하지 않는다.
- **이미지와 게시는 사람.** 텍스트만 자동으로 만들고 디자인과 최종 게시는 운영자가 한다.
