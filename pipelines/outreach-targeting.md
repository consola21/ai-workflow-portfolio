# outreach-targeting

평일 아침, 그날 SNS에서 직접 댓글로 소통할 소규모 브랜드 계정을 찾기 위한 업종·검색어·댓글 각도를 정해 알려 주는 작업. 댓글 자체는 사람이 단다.

```
schedule:  CRON_TZ=Asia/Seoul 20 9 * * 1-5
connects:  (없음 — 계산과 생성만)
output:    푸시 알림 + 검색어·해시태그·댓글 예시
```

## 왜 sns-autopost와 같은 공식을 쓰나

댓글을 받은 사람이 프로필에 들어왔을 때 **그날 올라간 자기 업종 글**을 보게 하려는 것. 두 작업이 같은 업종 순환식을 공유하고, 한쪽만 바꾸지 못하게 양쪽 설정에 명시했다.

## 실행 지시 (원본에서 내부 정보만 치환)

1. 오늘 날짜(KST)와 요일을 **코드로** 구한다. 토·일이면 알림 없이 종료.
2. 업종 = `목록[n mod 10]`, `n` = 2026-10-12(월)부터 센 평일 수. *(sns-autopost와 같은 목록·같은 공식)*
3. 업종 → 소분류 키워드 매핑에서 검색어 6~8개, 해시태그 4~5개를 만든다. 같은 업종이 2주마다 돌아오므로 `n div 10` 값으로 소분류 시작 위치를 바꿔 매번 다른 조합을 쓴다.
4. 댓글 각도 3개: 그 업종 소규모 브랜드가 올릴 법한 게시물 유형(신제품, 샘플 도착, 제작 과정, 포장, 재입고 등) 중 셋을 골라 댓글 예시 한 문장씩. humanizer로 다듬는다.
5. 대상 기준: 팔로워 500~5,000대 소규모 브랜드. 대형 브랜드·인플루언서·리셀러 제외.
6. 댓글 원칙: 영업 문구·링크·"DM 주세요" 금지. 게시물 속 구체적인 것 하나에 반응. 복붙 티 금지. 운영자 신원 비공개.
7. 푸시: "오늘 댓글 분류: {업종} — 검색어는 메시지 확인" → 메시지로 키워드·검색어·해시태그·댓글 각도 전달.
