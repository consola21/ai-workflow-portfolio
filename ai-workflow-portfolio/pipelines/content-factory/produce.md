# produce

```
schedule:  CRON_TZ=Asia/Seoul 54 8 * * 1,4
connects:  Google Drive, WebSearch
output:    drive/<CONTENT_FOLDER_ID>/{게시일}_{NN}_{주제}/슬라이드원고.txt, 캡션.txt
```

## 실행 지시 (원본에서 내부 정보만 치환)

매주 월·목 자동 실행. 오늘 게시할 카드뉴스의 슬라이드 원고와 캡션(텍스트)만 만들고, 독립 검증을 거친 뒤 운영자에게 전달한다. 이미지·영상은 만들지 않는다. 게시는 하지 않는다. 사람이 없으니 질문하지 말고 끝까지 진행하고, 판단한 내용은 결과 메시지에 적는다.
※ 드라이브 저장(5번) 전에 '문장 다듬기'와 '독립 검증'을 이 순서로 반드시 먼저 수행한다.

### 일정
- 게시는 매주 월·목 10:00(KST)에 운영자가 직접. 이 작업은 같은 날 08:54에 실행 → 게시일 = 실행일.
- 오늘이 월·목이 아니면 종료(audit의 재실행이면 함께 온 게시일 지시를 따름).
- 날짜 표기는 작업일인지 게시일인지 붙이고 요일도 함께. **요일은 코드로 계산.**

### 배경
- 주제: 소규모 브랜드가 이미 거래 중인 중국 공장 관리 실무. 해요체, 짧고 실무적, 과장 없음. 불확실한 수치는 "예시" 표기. 중국어 예문은 간체 + 한국어 번역.
- 운영자 신원 비공개: 실명·얼굴·회사명·짐작 가능한 사례 금지. 가격 금지.

### 지난주 인기 제품 반영
1. 지난주 = 이번 주 월요일(M, 코드로 계산) 기준 M-7 ~ M-1.
2. 먼저 `_주간인기제품_M.txt`(sns-autopost가 만든 캐시)를 읽는다. 부족할 때만 검색.
3. 검색은 그 기간 국내 기사·공식 발표만, **발행일 확인 필수**, 5~8회 이내.
4. 소규모 브랜드가 중국 OEM으로 만들 법한 카테고리만. 직전 3회차와 같은 카테고리는 피한다.
5. 브랜드명 금지, 판매 수치 게시물에 옮기지 않음.
6. 적합한 품목이 없으면 지어내지 말고 계절 품목을 쓰고 그렇게 적는다.

### 주제 순서
- 팁 · 사례 · 팁 · 안내 4회 패턴으로 주제 순서표를 운영. 이전 회차와 겹치지 않게.
- 사례 편은 일반 패턴으로 각색하고 "실제 경험으로 바꿀 부분"을 표시.

### 절차
1. 드라이브 하위 폴더 이름에서 **가장 큰 회차 NN을 찾고 이번 회차 = NN+1** (`_`로 시작하는 건 회차 아님). **오늘 날짜로 시작하는 폴더가 이미 있으면 새로 만들지 않고 보고만 하고 종료.**
2. 예시 품목을 정한다.
3. 슬라이드 원고 6~8장: 장마다 `[n/N] 유형 · 상단 라벨 · 제목 · 부제 · 본문 · 하단 노트`. 첫 줄 `NN회차 주제 (작성일 · 게시일 · 예시 품목)`.
4. 캡션: 도입(공감) → 핵심 요약 → 응원 한 문장 → 글 끝 두 줄(팁 = 저장 유도 / 사례 = 공유 유도 / 안내 = 문의 유도) → 해시태그.
   - 4-0. 문장 다듬기.
   - 4-1. 독립 검증 → 지적대로 수정.
5. `{게시일}_{NN}_{주제요약}` 폴더를 만들고 두 파일 저장.
6. 보고: 회차·주제·게시일, 예시 품목 근거(확인/추론), 원고·캡션 전문, `검증: 통과 N · 수정 N · 미검증 N`, 검수할 부분, 폴더명. 푸시: "NN회차 원고 준비 완료 — 오늘 10:00 게시".

### 문장 다듬기
- humanizer 스킬로 다듬는다(embedded mode, 최종 문장만). 사실·숫자·날짜·근거는 하나도 바꾸지 않고 문장 모양만 고친다.
- 이 작업의 말투·형식 규칙이 우선.
- **마감 09:20.** 못 끝내면 그 시점 문장으로 검증에 넘기고 "일부만 적용".

### 독립 검증
- **앞 과정을 보지 않은 새 하위 에이전트.** 넘길 것: 게시물 목적, 원고·캡션 전문, 사실 주장마다 근거 URL과 원문 발췌, 예시 품목 근거 기사. **작성 과정·추론은 넘기지 않는다.**
- 검증 항목(400단어 이내): 사실(인코텀즈 판본·통관 규정 등 개정 여부 포함) / 법(관련 관할 전부, 자문처럼 읽히는지) / 윤리(칸트) / 독자에게 알릴 위험(비용·법적 책임·안전).
- **마감 09:35.** 넘기면 검증 없이 저장하고 "독립 검증 없음".
