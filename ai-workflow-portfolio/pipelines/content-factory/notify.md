## 실행 지시 (원본에서 내부 정보만 치환)

매주 월·목 09:50 자동 실행. 운영자에게 "10시 게시 시간"을 폰으로 알린다. 질문하지 말고 빠르게 끝낸다. 게시·예약·파일 수정은 하지 않는다.

1. 오늘 날짜(KST)와 요일을 **코드로** 확인. 월·목이 아니면 종료.
2. 드라이브 `<CONTENT_FOLDER_ID>` 하위에서 오늘 날짜로 시작하는 회차 폴더를 찾는다(1~2회 조회).
3. 푸시:
   - 폴더 있음 → "10시 게시 시간이에요 — NN회차 {주제}"
   - 폴더 없음 → "10시 게시 시간인데 오늘 회차 폴더가 아직 없어요 — 제작 작업 결과 확인해 주세요"
   - 드라이브 조회 실패 → "10시 게시 시간이에요"만
4. 한두 줄 메시지: 회차·주제·폴더명, "캡션은 폴더의 캡션.txt".
